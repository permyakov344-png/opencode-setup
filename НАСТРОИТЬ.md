# Настроить эту машину

Файл-инструкция для агента OpenCode на новой машине. Достаточно сказать агенту:
**«прочитай НАСТРОИТЬ.md и сделай»** — дальше он действует по шагам ниже.

---

## Что сказать агенту (скопировать целиком)

> Настрой мне OpenCode как на рабочем компьютере. Репозиторий
> `permyakov344-png/opencode-setup`. Учти, что здесь macOS на Apple Silicon.
> Сделай по порядку: склонируй репозиторий, запусти `install.sh`, затем
> `verify.sh`, покажи результат проверки. Если скрипт спрашивает ключ RouterAI —
> спроси его у меня. Ничего не удаляй и не делай `git push --force`.

---

## Шаги для агента

### 1. Проверить, что есть

```bash
opencode --version
git --version
gh auth status
uname -sm          # ожидаемо: Darwin arm64
```

Если OpenCode не установлен — предложите один из способов:

```bash
brew install anomalyco/tap/opencode-v2
npm install -g @opencode/cli
curl -fsSL https://opencode.ai/v2/install | bash
```

После установки нужен новый терминал (обновится PATH).

### 2. Склонировать репозиторий

Репозиторий приватный, нужен вход в GitHub:

```bash
brew install gh        # если gh нет
gh auth login
gh repo clone permyakov344-png/opencode-setup ~/opencode-setup
```

### 3. Установить конфигурацию

```bash
cd ~/opencode-setup
bash install.sh
```

Скрипт:
- сделает резервную копию `~/.config/opencode` в `~/.config/opencode.backup-<дата>`;
- скопирует агентов, команды, `AGENTS.md` и `opencode.json`;
- спросит ключ RouterAI (или возьмёт из `$ROUTERAI_API_KEY`).

Ключ можно передать сразу, без вопроса:

```bash
bash install.sh --api-key "sk-..."
```

Нет ключа — установить без него: `--skip-key`. Всё, кроме модели по умолчанию,
будет работать.

На Windows то же самое: `powershell -ExecutionPolicy Bypass -File install.ps1`.

### 4. Проверить

```bash
bash verify.sh
```

Ожидаемо: `ок: 13   предупреждений: 0   проблем: 0`.

### 5. Перезапустить OpenCode и убедиться

В новой сессии набрать `/` — в списке должны быть `review`, `test`, `docs`, `sync`.
В списке сабагентов — `reviewer`, `tester`, `docs`.

---

## Чего делать нельзя

- `git push --force`, `git reset --hard` — история конфигурации не перезаписывается.
- Удалять `~/.config/opencode` целиком — там `service.json` и данные входа.
- Коммитить ключи: `config/opencode.json` в репозитории содержит заглушку
  `__ROUTERAI_API_KEY__`, реальный ключ остаётся только на диске.

---

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| PowerShell: «выполнение скриптов отключено» | запускать через `powershell -ExecutionPolicy Bypass -File install.ps1` |
| Кириллица в выводе Windows-скрипта кракозябрами | `chcp 65001` в том же окне, затем повторить |
| `./install.sh: bad interpreter` | запускать `bash install.sh`, а не `./install.sh`; проверить, что файл с LF |
| `verify` пишет `[нет]` на файлы | повторить установку, проверить права на `~/.config` |
| `verify` пишет «JSON не проверить: нет рабочего python3 или node» | не страшно: поставьте `brew install python3` или проверьте JSON глазами |
| Сабагент падает с «model not found» | модель удалили из каталога: заменить `model:` в `config/agents/<имя>.md`, затем повторить установку |
| `gh repo clone` — «not found» | `gh auth login`, проверить `gh auth status`; репозиторий приватный |
| Конфигурация «не подхватилась» | перезапустить `opencode` |

Откат: вернуть папку из `~/.config/opencode.backup-<дата>`:

```bash
rm -rf ~/.config/opencode
mv ~/.config/opencode.backup-2026-11-18_120000 ~/.config/opencode
```
