---
description: Сохранить изменения и синхронизировать проект с GitHub
---
Синхронизируй текущий проект с GitHub.

1. Проверь, что это git-репозиторий и настроен remote `origin`. Если нет — сообщи и остановись.
2. Выполни `git add -A`.
3. Если есть изменения — сделай `git commit` с коротким осмысленным сообщением по diff.
4. Определи текущую ветку: `git rev-parse --abbrev-ref HEAD`.
5. Выполни `git pull --rebase origin <ветка>`. При конфликте остановись, покажи конфликтующие файлы и не делай force push.
6. Выполни `git push origin <ветка>`.
7. Покажи итог: ветка, хеш коммита, что отправлено.

Запрещено: `git push --force`, `git reset --hard`, удаление файлов, коммит секретов (`.env`, токены, ключи).
